# rec/ — video explicativo

Este directorio contiene el video asciinema de **Arbitraje USDT: el spread que sí paga** y el reproductor
que se usa en la página del proyecto.

- `arbitraje.cast`: grabación original (asciicast v2).
- `arbitraje.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:15. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
